# ENCpatch v0.13.42

First public release. ENCpatch lets you control grandMA3 onPC from an Elgato Stream Deck — the encoders follow whatever's on MA3's encoder bar, no matter the fixture or page. It also speaks OSC to ETC Eos.

## Download & install

Download **ENCpatch-v0.13.42.zip** below — it contains the macOS DMG and a *Read Me First* install guide. Apple Silicon (M1 or newer) only.

The app is not notarized (no paid Apple Developer account yet), so macOS will claim it is "damaged" on first launch. It isn't — run this once after copying it to Applications:

```
xattr -cr /Applications/ENCpatch.app
```

Full setup steps (Stream Deck permission, MA3 bridge plugin import, Eos OSC ports) are in the bundled *Read Me First* guide.

## What's new in 0.13.42

- **Encoder bar now follows sub-page position within a feature group.** Previously, flipping Position to page 2 (X Focus / Y Focus / Z Focus / Position MSpeed) still showed and drove the page-1 attributes. A new single source of truth in the MA3 bridge (`resolveBarSlots()`) is used by both the wheel-tick handler and the LCD labels — the LCD always shows exactly what the wheel drives. Resolution reads MA3's live encoder-bar UI, falling back to a selected-attribute-anchored window, then the legacy sorted list.
- **`cycleSlotStack` is sub-page aware** — LCD-tap cycling anchors on the live bar's base attribute instead of sorted-slot-N.
- **New bridge diagnostics:** `probeEncoderBar` (dumps how each resolution strategy sees the current bar — run on two pages and diff to pin down UI-tree issues) and `setBarMode` (A/B lever: `auto` / `ui` / `win` / `legacy`, where `legacy` reproduces pre-0.13.42 behavior exactly).
- **Version handshake:** the app and the MA3 bridge Lua plugin must both be 0.13.42. Re-import the bridge plugin in MA3 after updating, or the app flags an old bridge and skips live bar reads.

## Also in the 0.13.x line

- Fixed "Save Bridge to Downloads" silently failing (404) in packaged builds (v0.13.41).
- Console picker with ETC Eos support, hot-reload of the console driver on settings change (v0.13.0–0.13.1).
- Bitfocus Companion module and native Stream Deck plugin scaffolds included in the repo.

## Requirements

- macOS on Apple Silicon (arm64)
- grandMA3 onPC 2.0+ (same machine), or an Eos-family console on the LAN
- Elgato Stream Deck — Stream Deck Plus strongly recommended
