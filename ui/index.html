    Console

    Which lighting console ENCpatch is controlling. Encoder ticks + page buttons route through the matching protocol (Lua bridge for MA3, OSC wheel keys for Eos, etc). v0.13.1+: changes apply live — no restart needed.

    When ON, the SD encoders fill with whatever Eos has on its encoder display in slots 1-4 (live from /eos/out/active/wheel feedback). When OFF, the encoders use the per-category param lists below. Try ON first for zero-config — if Eos returns the same 4 params regardless of category, turn OFF and use the per-category map.
    Toggles Eos's Custom Encoder Map mode on connect. Set up a custom map in Eos: Tab 40 → New Map, drop 4 wheels in your preferred order, save. ENCpatch's 4 encoders then mirror that map exactly.
    Comma-separated list of 4 Eos parameter names. When set, the SD encoders are hardcoded to those parameters and the LCD shows them as static labels. Find parameter names in Eos Tab 7 (Virtual Keyboard).

    Eos: encoder parameters per category

    When you press a category button on the Stream Deck (Intensity / Color / Image / Focus / Shutter / Form), the 4 SD encoders auto-swap to the parameter names listed below. Names are case-insensitive; use underscores for spaces (color_select matches "Color Select"). Find valid names in Eos Tab 7 → "OSC /key Names" or in any fixture's column headers in the Live Table. Each category supports up to 3 pages of 4 (12 params total) — fill in additional pages if your fixture has more params in that category, then press the same category button again on the SD to cycle to the next page. Empty trailing slots disable those pages (so a 4-param category stays single-page, an 8-param category gets 2 pages, 12 = 3 pages). (LCD swipe still works as an alternate navigation method.)

    Example: for the Rogue R2X Spot 21ch under Color, try Color_Select, Color_Wheel_Mode, Color_Select_2, Color_Wheel_Mode_2. Common errors: a typo'd or non-existent param name silently no-ops on Eos's side (check Eos's Tab 99 Diagnostics for "ProcessWheelCommand invalid parameter name").

    MA3 OSC ports

    Used only when the console is grandMA3. Match these to MA3 → Menu → Network → OSC. The listen port here must match MA3's "Output port", and MA3's "Input port" must match what you set as MA3 send port.

    MA3 Bridge plugin

    Required for fixture-agnostic encoder control. Save the plugin below, import it in MA3 (Menu → Plugins → +), then double-click to start. System Monitor should show [ENCpatch] listening on 127.0.0.1:9001.

    When ENCpatch and MA3 are on different machines, set the same token here AND in ENCpatchMA3Bridge.lua (TOKEN constant near the top). Required if you change the bridge's BIND_ADDR away from 127.0.0.1 — otherwise anyone on the LAN can send commands to MA3.
    Encoder stacks (LCD tap → cycle)

    Tap the Stream Deck Plus LCD above an encoder to cycle through stacked attributes. Define the cycle list per feature group + slot. Comma-separated MA3 attribute names. Empty = no cycle (single attribute on that slot).

    Auto-fill reads the currently-selected fixture in MA3 and asks the bridge which attributes are valid for each slot of the current feature group. Select fixtures of one type, pick a feature (Color / Gobo / etc.), click Auto-fill, then Save. Repeat per fixture type.

    Examples: Color slot 1 = Color1, Color1WheelSpin, Color1WheelShake. Gobo slot 1 = Gobo1, Gobo1Pos, Gobo1WheelSpin. Names must match MA3's exact attribute spelling — check the bottom-of-screen edit dialog tab labels.
