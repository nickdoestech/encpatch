# Assets checklist — things to request from Nick

The page should use real captures, not stock imagery. Ask Nick for:

1. **Hero shot** — photo of the Stream Deck Plus on a desk next to a Mac running
   grandMA3 onPC, LCD strip showing attribute labels (e.g. Pan / Tilt / Zoom /
   Focus). This is the money shot; a slightly moody desk photo beats a render.
2. **Hero GIF or short video (ideal)** — 5–10 s: select a fixture in MA3, the
   deck's LCD updates; turn a wheel, the beam/value moves in MA3; tap a feature
   key, both MA3 and the deck flip pages together. Screen-record MA3 + phone/cam
   on the deck, side by side.
3. **Web UI screenshots** — the mapping editor, the encoder stack editor, and the
   Settings console picker (127.0.0.1:8733). Light-mode or dark-mode to match the
   site's theme.
4. **LCD close-up** — macro shot of the strip showing 4 live labels.
5. **Eos setup screenshot** (for the Eos section) — Tab 40 Custom Encoder Map next
   to the deck mirroring it, if he has Nomad handy.
6. **App icon** — from the repo's build assets, for the page favicon/card.
7. **The "damaged" dialog screenshot** (optional, for the install note) — the macOS
   warning next to the one-line fix builds trust.

Practical notes
- Ask for PNG for UI captures, H.264 MP4 or an optimized GIF/WebM for motion.
- If Nick can't shoot photos yet, launch with UI screenshots + a simple diagram
  (deck → ENCpatch → MA3) and add photos later. Don't block the page on assets.
